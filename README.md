# Русский перевод Cisco Packet Tracer 9.0.1

Неофициальный русский перевод интерфейса Cisco Packet Tracer. Проект не связан с Cisco и не одобрен компанией Cisco.

## Состояние перевода

Каталог включает 10 603 сообщений Qt Linguist. Перевод создан с помощью автоматического перевода и выборочно вычитан с учётом сетевой терминологии Cisco. Сплошная ручная экспертная вычитка всех строк ещё не проведена; в длинных описаниях могут оставаться неточности.

Названия протоколов, команд IOS, брендов и форматов данных в основном сохранены на английском, чтобы они соответствовали оригинальной терминологии.

## Файлы

- [Russian_rus.ts](./Russian_rus.ts) — исходный каталог Qt Linguist; его можно редактировать.
- [Russian_rus.ptl](./Russian_rus.ptl) — собранный файл языка для Packet Tracer.

## Установка

Этот выпуск собран для Cisco Packet Tracer 9.0.1. С другими версиями совместимость не проверялась.

1. Закройте Cisco Packet Tracer.
2. Скопируйте `Russian_rus.ptl` в папку `C:\Program Files\Cisco Packet Tracer 9.0.1\languages`. Windows может запросить права администратора.
3. Запустите Packet Tracer и откройте **Options > Preferences > Interface**.
4. Выберите `Russian_rus.ptl` в списке **Select Language** и перезапустите программу.

Чтобы удалить перевод, закройте Packet Tracer и удалите `Russian_rus.ptl` из папки `languages`.

## Обратная связь и участие

Если вы нашли ошибку, создайте **Issue** и укажите:

- версию Packet Tracer;
- где встретилась строка;
- английский оригинал, текущий вариант и предлагаемый перевод;
- скриншот или короткий сценарий, если они помогут понять контекст.

Принимаются правки к `Russian_rus.ts` с кратким объяснением технического контекста.
